# Jesse Dunn

I'm building Access Tool, a free, privacy-first AI support tool for people navigating housing insecurity, income insecurity, paperwork, benefits, and crisis-adjacent systems in King County.

The live tool is here: https://access-tool-eight.vercel.app

The source is here: https://github.com/am-dj-ct/access-tool

## What I'm working on

Access Tool is a small public-interest software project with a simple promise: useful AI support should not only belong to people who already have money, time, stability, and institutional fluency.

The project is built around a few non-negotiables:

- No accounts
- No ads
- No analytics
- No conversation storage
- No premium tier
- Open source from launch
- Plain-language privacy and safety docs
- Human help surfaced when the model is likely to be weak

## What I care about

I'm interested in tools that are modest, inspectable, and useful in the real world. I care about privacy-preserving AI, public-interest software, local resource design, and interfaces that respect people who are stressed, tired, or trying to get through a hard day.

This profile is intentionally simple. The work should be auditable before it is flashy.
